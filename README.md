# Cahier de Vente CI

Cahier de caisse numérique simple et rapide pour enregistrer les ventes du jour en F CFA.

## Lancer en local

**Prérequis :** Node.js

1. Installer les dépendances :
   `npm install`
2. Lancer l'application :
   `npm run dev`

## Build de production

`npm run build`

Les fichiers statiques sont générés dans le dossier `dist/`.
